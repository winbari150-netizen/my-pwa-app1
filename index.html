🔊 தமிழ் குரல் அமைப்பு

Kinny தமிழில் பேச, உங்கள் சாதனத்தில் ஒரு Tamil text-to-speech குரல் நிறுவப்பட்டிருக்க வேண்டும். இது Claude-ஆல் கட்டுப்படுத்த முடியாத, உங்கள் சாதனம்/browser-இன் அமைப்பு.

Android (Chrome): அமைப்புகள் → System → Languages & input → Text-to-speech output → Google Text-to-Speech Engine ⚙️ → Install voice data → Tamil-ஐ தேர்ந்தெடுத்து டவுன்லோட் செய்யவும். பிறகு Chrome-ஐ மூடி மீண்டும் திறக்கவும்.

Windows: Settings → Time & Language → Language & region → Add a language → தமிழ் → "Speech" pack-ஐயும் சேர்த்து இன்ஸ்டால் செய்யவும் (சில Windows பதிப்புகளில் Tamil speech pack கிடைக்காமல் போகலாம்).

iPhone / iPad: Settings → Accessibility → Spoken Content → Voices → Tamil-ஐத் தேர்ந்தெடுத்து டவுன்லோட் செய்யவும்.

நிறுவிய பின் மேலே உள்ள "தமிழ் குரலை சோதிக்க" பட்டனை மீண்டும் அழுத்தவும்.
